# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, and assume good faith. Harassment of any kind is not
tolerated.

Report unacceptable behavior privately to the maintainers through a
[GitHub security advisory](https://github.com/TJKDev1/achartengine/security/advisories/new) or by
contacting @TJKDev1 on GitHub. Reports are kept confidential.
